## 四方向 KDD 当前实现

本轮在 zktest 的 `/home/zk_test/zk_projects/.bioradar-kdd-integration/radar`、分支 `codex/radar-kdd-20261030` 开发，现役主目录和生产数据不随隔离联调变化。固定真实输入为 12 份临床登记、10 份 Europe PMC 材料、5 份 SEC 原件和 8 份 WHO 通报；它们是本轮采用范围，不是全领域分母。完整队列经普通快照/计算 HTTP 接口提交，由现有 RQ worker 保存结果；自动监测批次与显式完整队列的结果分别保留，旧截断或算法失败结果不回写。

`research/datasets/build.py` 负责单位、成员、时点和资格；`research/mining/kdd.py` 负责纯计算；`research/mining/evaluation.py` 分别保存价值判断和容量决定。科研保留 TF-IDF 对照与固定向量聚类，无独立研究确认时允许明确的文档探索；管线区分登记、药物项目及待核图提示；商业只比较合格同口径期间；公共卫生可先描述真实通报，不能将通报数量写成发病率。单文档补证线索、描述性模式与已有支持的模式分开。

Fabric 提供固定版本的 `clean_text`、原生字段和出处；WeKnora 返回与同一原件版本、正文哈希及模型绑定的挖掘特征。特征缺失不丢原件，不用检索 top-k 缩小分母。李的 v2 调度可选择数据加工、计算、专业评价和取证，按每次实际产物重决策；本地加工或计算各计一次工具、零模型调用。汪、潘的方法通过独立 HTTP 服务使用雷达统一模型回调和账本，本地加载保留为显式兼容方式。

页面可查看全部算法候选、未入选原因和人工反馈；容量暂缓不等于没有价值。报告的 FAIL、REVIEW、NOT_RUN 以及未知费用在页面和导出中保留。新 v2 另列本轮实际片段阅读范围，Markdown 的系统范围前言与逐字未改的已核正文分开；没有范围记录的旧版导出不变。当前科研成稿曾停于 `method_input_invalid`，WHO 报告有 FAIL；修复和后续真实结果以 `evaluation/handoff-verification.json` 为准，不将计算完成或界面检查通过写成专业结论通过。

## 现在怎样工作

徐子雯的程序保存新资料后，Fabric 在同一次数据库提交中记下待发布的变化。后台发布程序保存原文版本，雷达继续读取新版本、运行已有算法；符合条件的线索自动建立调查，补查相关材料并保存出处。没有新资料时不会反复计算全库。

这条链不要求先完成图谱。普通正文可以用于文本线索，临床登记的明确字段可以用于状态比较；唐蔚雯核实的对象、关系和时间资料到达后，再进入相应计算。PrimeKG 用作背景与查找方向，不能替代逐条研究证据。

后台把三件事分开：新取得了什么资料、什么值得调查、什么有依据判为紧急。旧资料补录不等于新近科研进展，登记终止不等于药物疗效失败，程序补查的材料也不自动成为支持证据或专家判断。

网页的“情报雷达”页可查看后台状态、已处理位置、候选和调查，也能暂停或继续自动读取。页面刷新只是读取状态；已有的手动分析、图谱调查和历史研究入口继续保留。

## 长期专题

“情报雷达”继续从新增资料里发现尚未指定方向的线索。“长期专题”持续记住一个明确问题：它采用过哪些资料，上一版看到什么，什么新证据需要继续查。两者使用同一套来源、调查和权限。

专题先补查 Fabric 已采用的版本，再持续接收更新，不依赖雷达最近一批的短窗口。修改研究范围会保留旧版并重新检查；暂停后从原位置追赶。过去的观察、问题和引用不会被新版改写。

当前有四个起步模板：管线登记、科研动向、商业指标、公共卫生。政策、监管、供应、区域等可以使用同一结构；方向标签不自动带来数据或专用算法。

- 管线比较原生登记状态和计划节点，登记号与药物项目分开。
- 科研累计去重材料和文字线索；研究是否独立、时间是否可靠另行记录。
- 商业与公共卫生数值必须有明确对象、单位、期间和口径。输入者声明的值与已经逐字段绑定原件的值分开。
- 正式公告、重要修订和撤回可以单独成为待核问题，不必等词频异常。资料缺失或采集失败不能解释成平静。

有依据的变化进入既有调查，程序保存材料和追加查找回执。页面提供本版观察草稿、历次记录、固定原件与下载；专家判断仍由研究人员提交。报告数量不是情报质量指标。

## 公开历史按日推进

隔离历史回放使用 `MonitorService.advance_history_day`，由已有测试或评测入口显式传入 `mode="public_history_reconstruction"`、带时区的 `cutoff` 和许可来源。当天集合先固定，再走原有计算、专题和调查；同日中断恢复原任务，新日只能向前。该工作空间的普通监测和专题 tick 返回 `history_step_required`，不会改用当前资料。使用方法见[开发说明](docs/开发说明.md#公开历史的逐日执行)。

当前历史自动调度政策为 `history-new-visible-evidence-v1`：没有新可见版本时仍保存每日评价、原 `needed`、到期原因和未决风险，研判留为 `deferred`，不发送模型请求；它不表示已经完成研判或排除风险。预算、租约及模型调用使用真实执行时间。此处交付的是隔离执行与恢复能力，历史预警效果另行评价。

## 材料理解与判断更新

主动提问和后台线索共用调查流程：

1. 没有初始材料时，先从问题提出查询，读取 Fabric 已发布的原文版本。
2. 解读材料、列出支持与反对证据，围绕重要缺口继续查。
3. 问题涉及机制时调用汪鑫怡的 MechEvidence；研究综合和调查安排仍由雷达负责。
4. 潘倩的 BioCheck 根据原件及明确标注的研究上下文，先规划表达，再生成报告、核验全文，必要时修订复查；所选支持片段另外复核，结果单独保存。
5. 保存最终文字、实际核验结果和来源。新证据或追问产生新版，原版保留。

读取范围和预算以页面返回的实际配置为准。旧基线默认读取 10 份资料、合计 40000 字符；KDD 默认 32 份、100000 字符，每次查 8 份，新查询动作上限 16、点读上限 32（实际可用次数还受服务器总预算限制，页面按所选策略显示），每条查询最多 5 页（含首页）。续页不占新查询名额，仍计实际请求和执行步骤。产品默认总预算仍为 16 次模型请求、262144 token、1800 秒；独立试验使用 32 次、1048576 token、3600 秒及 16 次新查询，不自动修改现役配置。每次只为即将发出的请求检查额度，不预扣尚未发生的四个阶段。记录实际请求字节和平台 token 用量；有阶段实测校准才使用其比率，无实测明确按保守上限估计。已收到的回执先恢复，不重新付费。

前期结构化分析与最终报告分开保存。最终文字核验通过，表示该份文字经过所配置方法的检查；人工结论仍由研究人员提交。旧版比较说明进入最终交付内容时，一并接受核验。来源许可在读取时核对。

## 连续运行的范围

- 原文及图谱的提交、发布位置和雷达处理位置保存在数据库。中断后核对原任务继续，不靠内存记进度。
- 重复版本不重复启动计算。同一线索的普通更新有冷却时间，调查次数按小时限制；等待预算的线索保留。
- 全库探索使用有上限的当前窗口，长期专题另存累计贡献。文字趋势有明确时间范围和计算预算，未纳入的部分会说明；窗口数量不能冒充全领域分母。
- 已采用资料被更新或撤回时，相关调查保留旧判断并提示复查。启用语义分析后，程序另存一版机器分析和变化理由，人工判断仍由研究人员提交。
- 旧库存逐步补录，新写入优先。磁盘低于保留空间时停止新增复制，并明确显示暂停原因。

zktest 的后台进程由 systemd 管理，PostgreSQL、Redis 继续使用原 Compose 数据卷。网页调试服务不随后台启动。具体启动、停止、重试和回退见[开发说明](docs/开发说明.md#持续运行与维护)。

## 已有能力和还缺什么

系统已经把持续取数、候选筛选、材料解读、有目的补查与机器分析更新接到同一调查。下表说明实际能力和限制；一次案例通过不代表已具备全领域判断水平。

| 环节 | 当前实际情况 |
|---|---|
| 来源、原文版本与持续运行 | 已运行，支持更新、恢复、固定原件和范围记录；来源覆盖仍不完整 |
| 对象与关系 | 能读取已有图谱并校验部分引用；可靠项目谱系、关系证据和历史身份仍不齐 |
| 候选线索 | 原 11 类方法保留；新 KDD 按四方向选择适用方法并保存数据资格、全部候选和价值/容量原因，候选不等于结论 |
| 材料语义解读 | 已接模型解读固定原文，区分陈述、推断、否定与条件；输入可能只是摘要或局部原件 |
| 命题与证据比较 | 按命题保存支持、反对、限制及竞争解释，绑定原文；模型关系判断仍可能出错 |
| 调查规划与执行 | 首问与缺口查询均可执行；Fabric 固定原件与 WeKnora 检索候选分别记录，范围及用量可见 |
| 判断更新 | 后到材料触发新版机器分析；当前稿通过核验才比较旧命题，否则明确暂不能比较。旧版和人工判断各自保留 |
| 核验与效果评价 | 复用 MechEvidence 和 BioCheck 的专业方法及全过程记录；真实效果仍按独立用例持续评价 |

已实现 ClinicalTrials、FDA CRL、Europe PMC 与 WHO 的公开读取；现役固定刷新只有 WHO 和 Europe PMC 的限定查询，其他来源不能据此称已常驻采集。旧库七类来源通过统一发布入口逐步进入版本库。当前自动补查主要查 Fabric 已采用版本。WeKnora 检索及两个专业项目通过适配器接入，实际调用和限制见资产盘点；这些共享能力服务于雷达，不能代替雷达自身的研究组织与综合分析。

下一步扩大真实问题与来源覆盖，检查漏掉的反例、研究独立性和结论稳定性。数值与统计继续交给现有计算函数，模型承担文字理解和调查组织；不把通用模型检查写成已接通专业评价。

每项研究的路径验收用真实问题贯穿；雷达整体能力还须按上述四方向分别做多案例、负例、未入选资料抽查和持续更新评价。单项路径检查：读懂原文及其限制，找支持与反例，针对缺口继续取证，给出有条件的分析，再用后来到达的新证据修订它。检查原文是否支持每条关键陈述、遗漏是否足以改变结论、计算和时点是否正确。材料数量、调查记录数量及工程测试通过数都不能代替这项验收。至少有一个资料足以回答的有限命题得到正确解释，能说明否定和适用条件；一条反例或不同解释影响判断，并说明下一次补查为什么必要。资料不足可以保留未知，但全部返回未知也不能证明已具备研判能力。
